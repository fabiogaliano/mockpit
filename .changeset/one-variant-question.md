One choice, one question: an agent's variant question now shows every live variant it decides between, adding the ones the agent left out (by name, "Not in the agent's question"), so a second "Which variant?" no longer follows it with the same choices again. Hiding a variant answer archives that variant, with your reason, and bringing it back (from the question, Studio or `move --restore`) unhides it, so hidden answers never reappear elsewhere.
