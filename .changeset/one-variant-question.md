One choice, one question: an agent's alternative question now shows every live alternative it decides between, adding the ones the agent left out (by name, "Not in the agent's question"), so a second "Which alternative?" no longer follows it with the same choices again. Archiving an alternative answer archives that alternative, with your reason, and bringing it back (from the question, Studio or `move --restore`) restores the answer, so archived answers never reappear elsewhere.
