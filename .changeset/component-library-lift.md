Components form a library. A component with no area is shared, and `--group` files it by what it does (Actions, Inputs, Navigation, Feedback, Containers, or your own word; `publish --group`, `edit <slug> --group`, and the same on MCP and HTTP). Home's Components page shows Shared first, under its groups, then each area's own, and the sidebar opens Components into Shared and each area with components, each its own page; About on a component says "Shared · Cards" or its area, and the System page lists the shared ones first. A component of one area that screens of several areas show is offered a move to shared (About's Make it shared, and a nudge on publish and in feedback), never moved by itself. When you mark a screen Ready, the agent hears `followUps.lift`: the pieces the screen draws itself, where else each name appears, and any copy of a library component drawn inline. It swaps the copies for instances, lifts the rest into components the screen includes, and asks "Still iterating on any of these?"; your answer marks the screen Ready again at that version and every lifted component you didn't choose Ready, which the Tune drawer then shows. `mockpit edit` also takes the design's slug first (`mockpit edit receipt --area ''`).
