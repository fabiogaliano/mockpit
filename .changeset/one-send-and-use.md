One Send, and Use. More answers, More like this, Borrow, New version, New state and Draw no longer send on their own: each joins the draft and goes with the next Send. Send shows how many things it carries and opens a list of them, each line as the agent will read it and each one to take back, with a message for the whole. A feedback batch's reply carries the same words as `lines`. Use replaces Use this. On an idea, it takes the picks into the screen or component the idea is for, Main first, with the picked values as their defaults; frames without a pick wait, and the idea stays open while any do. The reply's `use` verdict names the picks (`picks`), and the product's `read` says which ideas it was used from (`usedFrom`). After a pick changes, the idea shows "Changed since Use", and nothing moves until the next Use. Neither Send nor Use archives anything: an alternative left out is only released from use.
