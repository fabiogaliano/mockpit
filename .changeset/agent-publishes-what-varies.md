Agents now publish what varies as alternatives or a choice knob and ask only when a choice blocks their next step: the nudges that asked for a question binding every set of alternatives, and for a question over every 2–3 option knob, are gone. The brief, the guide topics, the CLI help, the MCP tools and the skills say so in one voice. They also cover looks, marks in `read`, `--sheet`, `requests`, `reply.lines` and `usedFrom`, and treat a Use as an instruction to put the picks in the code. `mockpit watch` prints a Send's `lines`. A Use's line names each pick as the idea names it. `docs/migrating-to-picks-and-looks.md` walks an agent through moving an existing project to these conventions.
