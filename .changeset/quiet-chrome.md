Quieter Focus and Board. Focus has one bar: Try, Comment, Tune, the preview, the palette, a version menu (the versions, Compare, New version, and a dot for what's new), Use this and Send. The side panel only opens for a question, or for Spec and Activity from the ⋯ menu. Answered questions fold to one line each. The Spec shows three lines of How it works and one "draft" tag, with Edit on hover, and leaves out empty sections. A new version or new answers take the stage when nothing is unsent. The Board's bar shows the page name and "N changed ›", the shortcuts sit behind "?", and a system change is one line with Undo. Versions are named v3 everywhere, the System included, and copy across the viewer is shorter.
