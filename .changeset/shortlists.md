New idea: gather candidates from across a project into one named Studio. A bookmark on each Studio card saves that version; the first save asks for a name or an existing idea, and later saves take one click, with Undo. A gathered idea is its own mock holding copies, each labelled with where it came from, so the originals stay as they were, and Add candidate picks more from the project's other mocks. Its replies go to the agent last working in the project until one writes to it, and the Thread says which.
