Review from a phone without typing. Tap a part and react with 👍, 👎 or "More like this", or react to a whole variant from the stage head when a state has several. Reactions are draft part comments (`reaction`, `variant`), so they travel in the one reply, and the agent reads them as compact lines in `reply.reactions` (`👍 part "hero" (variant B)`) on every tier, apart from typed `comments`. The viewer installs to a home screen: a web app manifest (standalone, theme colours from the workspace mode), icons, and Apple meta tags. On a tokened workspace the manifest's start URL carries the key for a signed-in caller, so a home-screen launch signs itself in. The number of mocks owing answers shows in the tab title and, where the browser supports it, on the app icon badge, live while the viewer is open.
