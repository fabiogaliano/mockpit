A newer version of a design in use now takes over by itself. When the tab has focus the design moves to the new version, and ten seconds later it goes in use; the only button is Back to #1, with the count on it. Going back writes no decision and doesn't message the agent, and using an older version later no longer brings the newer one back. A draft, an open question, a tool in use or typing holds it to a small See pill, and touching the page stops the count and leaves Back and Use. Also tells agents with the mockpit plugin not to arm a Monitor, and others not to announce re-arming one.
